# Work order — H-008: Integrity check validates the pull request again

**Status:** proposed in its own pull request. Approve with `APPROVED WORK ORDER H-008` on that pull request; the approved revision is this file at the pull request's head commit at that moment (D-030). After merging, accept with `ACCEPTED H-008`.

- **Task ID**: H-008 (owner-directed hygiene; passes no gate)
- **Problem**: Aikido autofix PR #32 added `ref: ${{ github.base_ref || 'main' }}` to the `repository-integrity` checkout. On pull requests the check therefore validated `main`, not the pull request, so a pull request with a fabricated STATUS.md row or a broken link would pass. Nothing was merged in that state yet (it went in after PRs #29 and #30).
- **Objective**: keep Aikido's goal (a pull request cannot edit the checks that judge it) while checking the pull request's own files.
- **Files and changes**:
  1. `.github/workflows/repository-integrity.yml` — two checkouts: the pull request's files in `review/`, the check scripts from the base branch in `trusted/`; the trusted scripts check `review/`. One-time fallback to the pull request's scripts, with a visible warning, only while the base branch predates this change.
  2. `scripts/check_repository.py`, `scripts/verify_ledger.py` — accept `SEPTUVO_ROOT` (the tree to check); default unchanged.
  3. `docs/security/GITHUB_SECURITY_SETUP.md` — describe the trusted-script model; correct the claim that the live ruleset is bound to integration ID 15368 (read back 2026-10-14: not bound); record Aikido PRs #31–#35.
  4. This work order file.
- **Out of scope**: other Aikido changes (fenced-block skipping, legacy baseline, symlink checks) are kept as merged; the ruleset itself (owner setting).
- **Acceptance criteria**: both checks pass on this pull request; a local simulation shows the trusted scripts reject a fabricated STATUS.md row even when the pull request's own copy of `verify_ledger.py` is sabotaged.
- **Known limit**: a pull request that changes the check scripts is judged by the previous scripts; change scripts and the documents they check in separate pull requests.
- **Rollback**: revert the squash commit.
- **Stop point**: pull request ready for owner review.
