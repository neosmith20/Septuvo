# Septuvo — decision register

All security-sensitive choices require explicit owner approval and, when identified by the security model, qualified external review. States are **Owner decided** (with date and link), **Candidate**, **Open** or **Blocked** (M0-02). An owner-decided product direction is a requirement, **not** authorization to implement an original secure protocol.

## Open questions requiring written decisions before relevant tasks

1. Identity trust model: locally pinned peer public keys, server enrollment, optional organization PKI, renewal and revocation.
2. Hybrid KEM combiner and transcript authentication; formal downgrade resistance and identity binding.
